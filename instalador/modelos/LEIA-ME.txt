AMDLSS5 MOD {VERSAO}

Run AMDLSS5-Instalador.exe, click "Select game folder..." (or the game .exe) and Install.
To remove: run the installer, choose the game and click Uninstall (everything goes back as it was).
In game: use FSR 3.1. The neural network starts OFF: press F10 to turn it on (and off).
End opens the mod menu.
The package includes dlssnr_on_amd.ini with the mod settings. Uninstalling restores the folder as it was.

Requirements: AMD Radeon RX 9070 / RX 9070 XT (RDNA 4); DirectX 12 game with FSR 3.1.
Tested only on a Radeon RX 9070 XT, in Resident Evil Requiem, The Witcher 3: Wild Hunt (next-gen, DirectX 12),
Onimusha: Way of the Sword (demo), Cyberpunk 2077 and Monster Hunter Wilds.
Keep the payload folder next to the installer.

WARNING (AMD Adrenalin):
Before playing, turn off the Adrenalin metrics overlay and recording/instant replay and set performance tuning
to "Default" (no saved overclock); reboot after changing it. With them on the GPU can become very slow and hang
(black screen/TDR) while the game loads, with this mod and with the original one.
